# Puppeteer-demo
Demo of basic automation using Puppeteer

### Installation
**1. Navigate to directory where you want to save the project**

**2. Clone this project**
```
git clone https://github.com/Minal-singh/Puppeteer-demo.git
```

Then, Enter the project
```
cd Puppeteer-demo
```

Install all dependency
```
npm install
```

Run the project
```
node index.js
```
